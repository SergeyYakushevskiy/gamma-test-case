# Тестовое задание по ЯП Golang
### Задание 1
Cделать сервис авторизации и аутентификации на jwt c регистрацией пользователя. Субд обязательно reindexer. 
Обмен данными должен происходить в формате json.  Сервис должен уметь заблокировать учётную запись или аннулировать конкретную сессию.
Подготовить через  Postman/Yaak (рекомендуем именно yaak)


### Задание 2
Провести исследование, написать бенчмарки для разных методов сложения срок, найти оптимальные методы сложения строк.  

### Задание 3
Нужно реализовать CLI-приложение, которое потоково читает CSV-файл и обрабатывает его через pipeline на goroutines/channels.

Приложение должно считать сумму двух колонок, заданных в JSON-конфиге, добавлять в выходной CSV поля sum и below_threshold, а также формировать JSON-отчёт со статистикой.

Обработка строк должна выполняться через worker pool. Количество worker’ов задаётся в конфиге. Несмотря на параллельную обработку, порядок строк в выходном CSV должен совпадать с порядком строк во входном файле.

Writer и statistics collector должны получать все обработанные строки. Нельзя использовать один общий канал как источник для двух конкурирующих consumer’ов.

Программа должна корректно обрабатывать ошибки, не загружать весь файл в память, не иметь гонок данных и проходить запуск с -race.
